ngx-form-draft

Zero-dependency Angular library for automatic form draft auto-save and restore using localStorage.

ngx-form-draft automatically saves your Angular form values to localStorage as the user types and restores them on page reload, so users never lose their work. It supports both Reactive Forms (FormGroup, FormArray) and Template-driven Forms (ngForm), with no external dependencies and no Angular animations module required.

  • Auto-saves form values to localStorage with configurable debounce
  • Restores drafts on page reload or navigation
  • Works with Reactive Forms and Template-driven Forms
  • Handles nested FormGroup and FormArray
  • Visual banner with discard option, pure CSS with no animations module needed
  • 7-day draft expiration built-in
  • Exclude sensitive fields like passwords from being saved
  • Customizable banner text for i18n support
  • Compatible with Angular 14, 15, 16, 17, 18, 19 and 20

Installation

npm install ngx-form-draft
